# Notes app — illustrative project context

## Mission
Build a fast, accessible note-taking web app with offline support, sync and full-text search.

## Roadmap themes
Reliable sync and conflict handling; search; keyboard-first UI; accessibility; test coverage for the API and the client.

## Non-goals and approvals
No native mobile apps yet. No release, deploy or merge without explicit owner approval. Example only: replace these assumptions with your project's before use.

## Domain review checklist
For sync or storage changes also check data-loss paths, migrations, offline behaviour and backward compatibility of the API.
